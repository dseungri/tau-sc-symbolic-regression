# Full-Cohort Nested Tenfold Protocol

This protocol defines a new participant-level nested 10-fold cross-validation
analysis for the original two-time-point cohort. The protocol is frozen before
its own execution and is isolated from previous outcome artifacts, model rankings,
figures, and held-out-result summaries.

## Cohort Contract

The analysis uses all 163 matched participants. Each participant contributes one
baseline tau vector, one approximately one-year follow-up tau vector, and one
static 160-by-160 structural-connectivity matrix.

The accepted preprocessing is preserved: whole-brain-normalized fiber-count
connectivity is symmetrized, diagonals are set to zero, no positive edges are
thresholded away, zero-degree nodes are rejected, and the subject-specific
symmetric-normalized graph Laplacian is used. Tau values are brainstem-referenced
SUVR and the time coordinates are `[0.0, 1.0]`.

## Fold Design

Outer folds are generated by a seed-42 participant permutation followed by
`numpy.array_split`. Because 163 is not divisible by 10, three folds contain 17
participants and seven folds contain 16 participants. Every participant appears
in exactly one outer-evaluation fold.

For each outer fold, the remaining nine folds form the outer-development set. A
single deterministic inner validation split is created from the outer-development
participants using:

```text
inner_seed = master_seed + 1009 * (fold_index + 1)
```

The same inner split is used for all comparable trained model paths in that
outer fold. After inner selection, the selected configuration is refit on all
outer-development participants for `best_epoch + 1` optimizer updates, then
evaluated once on the outer fold.

## Models

The prespecified paths are:

- persistence;
- ridge/no-network baseline with the existing alpha grid;
- diffusion-only reaction-diffusion;
- linear reaction-diffusion;
- quadratic reaction-diffusion;
- zero-anchored neural reaction-diffusion with seeds 41, 42, and 43;
- symbolic reaction-diffusion distilled from the selected refit neural model.

The symbolic path samples the selected neural reaction only on the
outer-development trajectory domain. PySR uses binary operators `+`, `-`, and
`*`, no unary operators, `model_selection="best"`, seed 42, and the existing
deterministic isolated-worker lifecycle.

## Metrics

Residuals are defined as `predicted - observed`. The aggregate summary reports
MSE, RMSE, MAE, bias, residual variance, residual standard deviation, and
secondary descriptive R-squared. RMSE and R-squared are not described as
accuracy.

The primary comparison is:

```text
RMSE_quadratic - RMSE_linear
```

Negative values favor the quadratic reaction. Secondary participant-level paired
bootstrap comparisons are listed in `config/cohort_tenfold_protocol.json`.

## Privacy

Freeze, checkpoints, predictions, figures, summaries, and audit outputs are
private artifacts and must be written outside the repository with restrictive
permissions. Console output is aggregate-only and must not include private paths,
filenames, participant identifiers, fold-membership lists, raw vectors, residual
vectors, or subject-level results.
